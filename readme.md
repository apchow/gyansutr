# 🧠 GyanSutr — Sovereign Unified Trusted Retrieval

**GyanSutr (S.U.T.R.)** is a 100% offline, local-first Sovereign AI second brain for students, researchers, and investigative journalists. Every document ingestion, vector embedding, RAG query, note, flashcard deck, and cryptographic audit log runs strictly on your machine—**zero cloud APIs, zero telemetry, and complete data privacy.**

---

## ⚡ Quick Start: Download & Run on Any PC (Windows, Linux, macOS)

### Step 1: Install Prerequisites (2 Minutes)
1. **[Ollama](https://ollama.com/download)** — Runs your local AI models offline.
2. **[Python 3.10+](https://www.python.org/downloads/)** — Make sure to check **"Add Python to PATH"** during Windows installation.
3. *(Optional for scanned image PDFs)* **[Tesseract OCR](https://github.com/tesseract-ocr/tesseract)** — Used only when a PDF page contains scanned images instead of selectable text.
